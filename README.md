# 接口报错模拟（Web API Mock）

一个 Tampermonkey 用户脚本：在浏览器里按规则改掉指定接口的返回，用来测前端的异常处理——500、超时、断网、空列表、登录失效这些平时不好造的场景。

只改浏览器这一侧，不需要代理、不需要装证书，也不用动后端。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)。
2. Chrome 要在「扩展程序 → Tampermonkey → 详情」里打开「允许运行用户脚本」，否则脚本不执行。
3. 打开 [mock-error.user.js](https://raw.githubusercontent.com/sleepray/Web-api-mock/main/mock-error.user.js)，在 Tampermonkey 弹出的页面里点「安装」。

装好后，任意网页的右下角会出现一个半透明的 **Mock** 按钮。

## 怎么用

1. 在页面上正常操作一下，让要测的接口发一次请求。
2. 点 **Mock** 按钮打开面板，在「最近的请求」里找到那个接口，点「建规则」。接口的方法、路径，连同它这次真实返回的状态码和响应体，都会带进规则里。
3. 改状态码或响应体；或者直接点预设。
4. 回到页面再触发一次这个接口，看前端怎么表现。

### 预设

| 按钮 | 效果 |
|---|---|
| 500 / 502 / 504 / 401 / 403 | 设成这个状态码，响应体换成对应的报错内容 |
| 断网 | 网络错误，请求发不出去 |
| 慢 3 秒 | 其它不变，等 3 秒再返回 |
| 空列表 | 返回 200，把响应体里的列表清空、总数归零 |
| 不返回 | 请求一直挂着，看加载中的样子和前端的超时处理 |
| ↺ 复原 | 回到刚建好规则时的样子 |

### 规则能设什么

- **匹配**：请求方法 + URL 里包含的一段文字；以 `re:` 开头的按正则匹配。
- **返回**：状态码（填 `0` 表示网络错误）和响应体。响应体像 JSON 却不合法时会提示具体位置。
- **延迟**：等多少毫秒再返回。
- **最多命中几次**：比如填 1，可以测「第一次失败、重试成功」。

### 三种模式

| 模式 | 请求到不到服务器 | 用途 |
|---|---|---|
| 拦截（默认） | 不到 | 最常用。后端什么都没发生，安全 |
| 放行 | **到，并且真的执行** | 模拟「服务端已处理，前端却收到失败」 |
| 挂起 | 不到，也一直不返回 | 看加载状态、测前端超时 |

> **放行模式要小心**：请求会真的发到服务器并执行，页面只是看到被改过的返回。下单、支付、审批这类接口照样会真的生效。

## 别忘了关

规则存在浏览器里，刷新页面后仍然生效。忘了关的话，过几天打开页面看到接口报错，很容易当成真的 bug。为此：

- 有规则生效时，Mock 按钮变红并显示条数。
- 面板右上角有「全部暂停」。
- 按钮被隐藏时，带着生效的规则打开页面会弹几秒提示。

## Mock 按钮碍事的话

- **拖动**：按住按钮拖到任意位置。
- **贴边**：拖到窗口边缘松手，按钮缩进去只露一小截，鼠标移上去再滑出来。
- **隐藏**：面板里点「隐藏按钮」。要再显示，可以点 Tampermonkey 弹出菜单里这个脚本下面的「显示 Mock 按钮」，或按 `Alt+Shift+M`（Mac 是 `⌥⇧M`），或在 DevTools 控制台输入 `__apiMock.show()`。

脚本默认在所有网站上运行。不想让它出现的网站，在 Tampermonkey 里打开这个脚本的「设置」，加到「用户排除」。

## 管不到的

只对页面里用 `fetch` 和 `XMLHttpRequest` 发的请求生效。下面这些改不了：

- 页面跳转、表单提交、链接触发的文件下载
- 图片、脚本、样式等静态资源
- WebSocket
- Service Worker 里发出的请求

## 更新

点面板右上角的「检查更新」。有新版本时按钮会变成「更新到 x.y.z」，点它会打开 Tampermonkey 的更新页，在那页点「更新」后刷新页面即可。

GitHub 的文件地址有几分钟缓存，刚发布的版本可能要等一会儿才查得到。

## 数据去哪了

- 规则只存在**当前网站**的 `localStorage` 里，各网站互不影响。
- 脚本不上传任何数据。唯一的对外请求是「检查更新」时读取本仓库里的脚本文件。

## 开发

单文件，没有构建步骤。改完检查一下语法：

```bash
node --check mock-error.user.js
```

发布：把文件头部的 `@version` 调大，推到 `main` 分支。
